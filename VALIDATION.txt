Validation for v0.1.0 — 2026-11-07

Automated render tests
  npm test
Runs 24 assertions groups against the actual JavaScript mods with mock
GPUI builders. Each test resets its data. Captured title strings are read
from tests/title-captures.json. No npm dependencies are required.
GitHub Actions runs the same command on Node 18, 22 and 24.

Native macOS checks and screenshots
  python3 scripts/native-demo.py
Requires installed Herdr Desktop 0.1.13, herdr-core, and Python 3.
The script creates a separate app home and core session, checks both mods,
opens controlled demo terminals, and records screenshots. It stops only
its own app/core on exit. It never launches a model or changes user sessions.
The disposable scratch directory is printed and retained for diagnostics.
Check output: tests/session-labels-agents-check.txt and
              tests/session-labels-pane-check.txt
Status output: tests/native-status.json
Screenshots: preview.png, docs/after.png, docs/before.png, docs/narrow.png,
             docs/renamed.png, docs/narrow-renamed.png
The before view uses the bundled shipped 0.1.13 agent-sidebar fixture;
it is not a comparison against current upstream master.

Baseline provenance
The baseline is the installed shipped 0.1.13 agents mod copied without edits.
To compute its checksum:
  shasum -a 256 tests/baseline/agents.js
The original hash is recorded in tests/baseline/SHA256.txt. A matching hash
checks this snapshot, not the authenticity of a separate installation.

Scope and limits
Native checks passed on Herdr Desktop 0.1.13/macOS. The mocked tests do not
validate native rendering. Native Linux/Windows, later Herdr binaries,
restart persistence, remote machines and sub-agent keyboard navigation
remain unverified. OpenClaw uses protocol fixtures, not a bundled adapter.
Title-format evidence and its limits are in tests/title-captures.json.
